## 文档说明

### [ANALYTICS.md](./ANALYTICS.md)

数据埋点（PostHog）长期维护文档，包含：
- 采集机制（SDK / background HTTP 两条通道、匿名 ID、遥测开关、隐私边界）
- 现存事件清单（事件名 / 属性 / 触发位置 / 用途）
- 属性规范（禁用自由文本、命名约定）
- 建议新增埋点（P0–P3，含激活漏斗与用户自定义 Actions）
- 埋点维护流程与变更记录

**新增 / 修改埋点后必须同步更新此文档。**

### [images/](./images/)

存放文档中使用的图片资源，包括：
- 架构图
- 流程图
- UI 截图（设置页改造前/后原型见 `images/options-ui/`）
- 组件示例

### [OPTIONS_UI.md](./OPTIONS_UI.md)

设置页 UI 设计规范（长期维护），包含：
- 现状问题清单（版面 / 层级 / 一致性 / 交互）
- 设计决策：蓝色唯一主色、全宽行式版面、**即时保存 vs 草稿保存的判定标准**、卡片级保存条、分区切换 + 滚动归零 + hash 深链
- 各分区规格（哪张卡有保存条、哪些操作即时生效）
- 组件层与 token 规划、实现细则（草稿钩子、与 `shared/ui` 的边界、埋点注意事项）
- 分阶段实施计划与「新增设置项检查清单」

**改动 `src/entrypoints/options/` 下任何 UI 之前必读。**

### [TOOLING.md](./TOOLING.md)

素材与设计工具总览（长期维护），包含：
- 工具矩阵：6 个脚本（图标生成 / 图标库打包 / 图标库校验 / 截图拍摄 / 截图合成 / 宣传图）+ 2 项文案 / 设计输入资产
- 每个工具的入口命令、输入产物、关键参数与环境变量
- 已知问题清单（依赖挂在 `/tmp`、`data-ready` 死代码、清单硬编码等，**均未修复**）
- 「改了什么要重跑哪个工具」对照表 + 环境自检命令

**在写新的素材 / 设计脚本之前必读，避免重复造轮子。**

### [I18N_LOCALE_REGISTRY_PLAN.md](./I18N_LOCALE_REGISTRY_PLAN.md)

i18n 语言注册表重构方案（把语言清单收敛到唯一真源），包含：
- 现状盘点：语言清单散落 5 处、`UNSUPPORTED_CHINESE_SCRIPT` 黑名单与「中文优先」的 bug 风险
- 目标结构：`src/shared/i18n/registry.ts` 作为唯一真源，`Locale` / 校验 / 选项 / 提示词名全部派生
- 通用匹配算法（书写系统淘汰 + 打分）与「跟随浏览器」判定规则
- 五处枚举收敛对照表、设置页控件由分段改下拉
- 验证门禁（`scripts/check-i18n.ts`）、分阶段提交计划、迁移与「加一门语言」checklist

**加语言 / 改语言判定逻辑之前必读。**
